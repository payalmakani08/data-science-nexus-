About Data Science

Data Science is a field that uses data, statistics and programming to understand information and make better decisions.

Why is it useful?

Data science helps people find patterns, understand trends and make decisions using data.

It is used in healthcare, education, business, sports, banking and many other areas.

  • Understand data and its patterns
  • Make decisions using information
  • Build useful prediction models
  • Present results using charts
