# DS/NEXUS — Data Science Blog

DS/NEXUS is a simple, responsive educational blog about data science,
artificial intelligence, Python programming and data visualization.

The website is designed to make technology easier to explore through
short, beginner-friendly article summaries and a clean layout.

## Features

- Gradient hero section and colourful design
- Responsive layout using Bootstrap 5
- Topic cards for exploring different subjects
- Article cards loaded from a JSON file
- Simple article search
- Category filtering
- Mobile-friendly navigation
- Clean typography and readable content

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- JSON
- Bootstrap Icons

## Project Files

- `index.html` — Main website structure
- `style.css` — Website design and responsive styling
- `app.js` — Article loading, search and category filtering
- `posts.json` — Article information

## How to Run

1. Keep all four files in the same folder.
2. Open the project using a local development server, such as VS Code Live Server.
3. Open `index.html` in your browser through that server.

The website can also be hosted using GitHub Pages.

## Adding Articles

Open `posts.json` and add another article object to the array.
Include its title, category, description, date, reading time, icon
and cover style.

Use the existing article objects as examples.

## Purpose

This project demonstrates the fundamentals of front-end web design,
responsive layouts, JSON data and basic JavaScript.

Made for curious minds.
